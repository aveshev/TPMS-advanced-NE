# Persistent TPMS

An Android app for Bluetooth tyre pressure sensors, with persistent background monitoring. It is
an open-source fork of [TPMS Advanced](https://github.com/VincentMasselis/TPMS-advanced) by
Vincent Masselis, released under the Apache License 2.0.
